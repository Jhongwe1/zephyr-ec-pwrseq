# docs/img/

架構圖、狀態機圖、標註後的波形圖。

---

## ⚠️ 架構圖必須你自己畫 — 這件事不能外包

README 目前用的是 ASCII 圖。它堪用，但**還缺一張你自己畫的**。

**為什麼這件事重要（而且是唯一我不能幫你做的事）：**

一張精緻、對齊完美、配色專業的架構圖，在 2026 年是**負面訊號**——
看的人第一個念頭是「這是生成的」。反過來，一張手畫的、線條歪歪的、
但每一塊都標對了名字的圖，證明的是**畫的人腦子裡真的有這個系統的模型**。

**醜沒關係。自己畫的才是訊號。**

## 怎麼做（15 分鐘）

1. 拿一張白紙
2. 畫四塊：**EC MCU** ／ **RC 網路** ／ **邏輯分析儀** ／ **PC**
3. 畫它們之間的線，標上訊號名稱：`EN_S5`、`PG_S5`、`UART1_TX`、`SWD`…
4. 光線充足的地方拍照，存成 `docs/img/architecture.jpg`
5. 更新 README §2 引用它

不想手畫就用 draw.io / Excalidraw——一樣是你自己排的版，一樣算數。

## 檢驗標準

畫完之後，蓋住圖，**用嘴巴把訊號從電源鍵一路講到 `PCH_PWROK`**。
講不順的地方，就是你其實還沒搞懂的地方——那才是這張圖真正的價值。
