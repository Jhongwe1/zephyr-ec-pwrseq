# docs/img/

架構圖、狀態機圖、標註後的波形圖。

---

## ⚠️ 架構圖要自己畫

README 目前用的是 ASCII 圖。它堪用，但**還缺一張真的把訊號畫出來的**。

**為什麼要自己畫：** 畫的過程會逼出你還沒想清楚的地方。
一張排版完美、但方塊之間的訊號名稱填不出來的圖，代表的是還沒搞懂；
一張線條歪歪、但每一條線都標得出名字與方向的圖，代表的是搞懂了。

**這張圖的價值在畫的過程，不在成品好不好看。醜沒關係。**

## 怎麼做（15 分鐘）

1. 拿一張白紙
2. 畫四塊：**EC MCU** ／ **RC 網路** ／ **邏輯分析儀** ／ **PC**
3. 畫它們之間的線，標上訊號名稱：`EN_S5`、`PG_S5`、`UART1_TX`、`SWD`…
4. 光線充足的地方拍照，存成 `docs/img/architecture.jpg`
5. 更新 README §2 引用它

不想手畫就用 draw.io / Excalidraw——一樣是你自己排的版，一樣算數。

## 檢驗標準

畫完之後，蓋住圖，**用嘴巴把訊號從電源鍵一路講到 `PCH_PWROK`**。
講不順的地方，就是你其實還沒搞懂的地方——那才是這張圖真正的價值。
